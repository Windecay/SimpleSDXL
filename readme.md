**SimpAI**（原 SimpleSDXL）是一个集成了 Fooocus 易用性与 ComfyUI 强大工作流的创意生图平台。通过全新的架构设计，SimpAI 实现了 WebUI 与 ComfyUI 的完美融合，让创意无限延伸。

## 🌟 核心亮点

### 1. SimpAI 启动器 3.0
- **双模式管理**：一个启动器轻松开启和切换 WebUI 模式与 ComfyUI 工作流模式。
- **全能管理**：便捷管理模型、自定义节点、启动参数及网络设置。
- **一键部署**：环境配置简洁高效，无需繁琐操作即可快速上手。

### 2. 双模驱动，灵活高效
- **WebUI 模式**：继承并增强了 Fooocus 的简洁交互，适合快速创意生成。
- **ComfyUI 模式**：
  - 支持从 WebUI 直接进入或独立启动。
  - **自动补全**：所有预置包自带的工作流支持一键自动补全模型，无需手动查找下载。
  - **API 驱动**：WebUI 底层使用 ComfyUI 工作流 API 处理大部分任务，兼顾简洁与强大。

### 3. 强大的 WebUI 控件
SimpAI WebUI 内置了丰富的创意工具，让图像编辑更得心应手：
- **即时图层编辑**：传入图片即可使用图层编辑器进行精细修改。
- **图片中转站**：方便图片在不同任务间流转。
- **划像对比**：直观对比生图效果。
- **3D 辅助**：内置三维摄像机与打光控件，精准控制画面光影与构图。
- **视频分割**：集成 Sam3 视频分割器，视频编辑更轻松。

### 4. 智能辅助与模型支持
- **多语言支持**：拥有丰富的双语翻译模块，打破语言障碍。
- **VLM 智能体**：利用视觉语言模型（VLM）进行提示词的智能扩写与翻译，精准理解创意意图。
- **前沿模型库**：紧跟开源社区，支持 **Qwen**, **Wan2.2**, **Flux2Klein** 等强力模型。
- **全能创作**：无论是图像生成、图像编辑，还是视频生成、视频编辑，都能轻松驾驭。

### 5. 企业级特性
- **分布式身份管理**：WebUI 可选择开启多用户模式，分离相册与个人设定，保障数据安全与个性化管理。
- **本地部署**：数据完全本地化，安全可控。
